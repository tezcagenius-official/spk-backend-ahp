## Installation

Clone the repository

```bash
  git clone git@github.com:tezcagenius-official/spk-backend-ahp.git
```

Switch to the repo folder

```bash
  cd spk-backend-ahp
```

Install dependencies

```bash
  npm install
```

create file environtment

```bash
  touch .env
```

create a database in your local

## Running Project

push database

```bash
  npx prisma db push
```

running project

```bash
  npm run start:dev
```
